# Лаба 2. База данных

Данные переезжают из памяти в реляционную базу (PostgreSQL или SQLite) и переживают перезапуск. Появляется вторая сущность своей темы, связанная с главной как один ко многим, с вложенным маршрутом `/api/<главные>/{id}/<связанные>`: создание и список. Схема создаётся из репозитория, строка подключения берётся из переменной окружения, значения в SQL передаются параметрами.

Срок: PR из `lab-2` в `main` до 23:59 накануне встречи 3.

## ★ (2 балла): миграции, индекс, поиск

Все три части дают 2 балла, две дают 1.

- Миграции через инструмент (Alembic, Prisma, Flyway, goose, EF Migrations, Knex) и сиды: команда, которая заполняет пустую базу тестовыми данными.
- Индекс под частый запрос, создаётся миграцией. В README запрос, `EXPLAIN` и его вывод, где база использует индекс.
- Поиск `GET /api/<items>?q=слово` по названию без учёта регистра, ищет база.

## ★★ (2 балла): правило темы и статистика

- Правило темы из [списка тем](themes.md): при нарушении сервер отвечает 409 и объясняет причину. Проверка и запись в одной транзакции.
- Статистика с агрегатным запросом: `GROUP BY`, `COUNT`, `SUM`, `AVG`. Считает база, а не цикл в коде.

## contract.json: что добавить

```json
{
  "text_field": "title",
  "search": { "param": "q", "field": "title" },
  "child": {
    "resource": "loans",
    "create": { "reader": "Иванов", "taken_at": "2026-10-01" },
    "parent_field": "book_id"
  },
  "rule": {
    "description": "Нельзя выдать книгу, если все экземпляры на руках",
    "parent": { "copies": 1 },
    "setup": [{ "method": "POST", "path": "/api/books/{id}/loans", "body": { "reader": "Иванов", "taken_at": "2026-10-01" } }],
    "violate": { "method": "POST", "path": "/api/books/{id}/loans", "body": { "reader": "Петров", "taken_at": "2026-10-02" } },
    "expect_status": 409
  },
  "stats_path": "/api/books/stats"
}
```

| Поле | Что писать |
| --- | --- |
| `text_field` | Строковое поле главной сущности, в которое чекер запишет строку с SQL-инъекцией |
| `child.resource` | Имя связанного ресурса из пути: для `/api/books/{id}/loans` это `loans` |
| `child.create` | Правильное тело для создания связанной записи |
| `child.parent_field` | Как называется поле связи в ответе, например `book_id` |
| `search` | Только для ★: параметр поиска и поле, в котором ищется слово |
| `rule` | Только для ★★. Чекер создаёт родителя (поля из `parent` подставляются поверх `create`), выполняет запросы из `setup`, потом запрос `violate` и ждёт `expect_status`. `{id}` в пути заменяется на id созданного родителя |
| `stats_path` | Только для ★★: адрес статистики |
